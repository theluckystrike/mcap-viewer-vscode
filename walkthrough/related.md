# Free Zovo extensions for other data files of a robotics project

- SQLite Viewer opens .db and .db3 files, such as ROS 2 bags in the SQLite format, as tables.
- Parquet Viewer opens .parquet files with their schema and nested data.
- HDF5 and NetCDF Viewer browses groups, attributes and values in .h5 and .nc files.

Each link opens the extension page. Nothing installs until you click Install there.
